# Chapter 5 Atomic structure
## 5.1 Elements, atoms and symbols
### Key definitions
‑=={red}**Element**==: A pure substance made of only one type of atom, ==cannot be broken down into simpler substances by chemical methods.==
‑**Atom**: The smallest basic particle of an element that retains chemical properties of the element.
‑**Chemical symbol**: A one‑ or two‑letter abbreviation used to represent an element (e.g. Na for sodium, Fe for iron). First letter capital, second letter lowercase.

### DSE note
Elements are classified by the number of protons in their atoms. Atoms of the same element have the same proton number.

## 5.3 Atomic number and mass number
### Definitions
1. ==**Atomic number (proton number, Z)**==
The number of protons in the nucleus of an atom.
‑All atoms of the same element have the same atomic number.
‑In neutral atom: atomic number = number of protons = number of electrons.

2. ==**Mass number (nucleon number, A)**==
Total number of protons + neutrons in the nucleus.
$$Mass\;number=protons+neutrons$$
Number of neutrons = mass number − atomic number.

### Notation for an atom
$$_Z^A X$$
$X$: element symbol; $Z$: atomic number; $A$: mass number.

Example: $_11^{23}Na$
Atomic number =11, mass number=23
Number of protons=11, electrons=11, neutrons=$23‑11=12$.

## 5.4 Isotopes
### Definition
Isotopes are atoms of the same element with the ==same atomic number (same proton number) but different mass numbers (different neutron numbers)==.

### Table 5.5 Isotopes of some elements in nature
|Element|Isotopes|Atomic number|Mass number|Relative abundance of isotopes in nature (%)|
|---|---|---|---|---|

|Carbon|$_6^{12}C$<br>$_6^{13}C$<br>$_6^{14}C$|6<br>6<br>6|12<br>13<br>14|98.892<br>1.108<br>very small|
|Oxygen|$_8^{16}O$<br>$_8^{17}O$<br>$_8^{18}O$|8<br>8<br>8|16<br>17<br>18|99.76<br>0.04<br>0.20|
|Chlorine|$_{17}^{35}Cl$<br>$_{17}^{37}Cl$|17<br>17|35<br>37|75.4<br>24.6|

### ==Properties of isotopes==
1. ==Chemical properties are identical==: same number of outer‑shell electrons, which determines chemical behaviour.
2. ==Physical properties differ== (density, melting point, boiling point) because they have different numbers of neutrons and different atomic masses.

Example: Isotopes of chlorine: $_{17}^{35}Cl$ and $_{17}^{37}Cl$
‑Protons:17 for both; neutrons:18 and 20 respectively.

### DSE common misconception
Isotopes have same proton number, different neutron number, not different electron number.

## 5.5 Relative isotopic mass and relative atomic mass
### 1. Relative isotopic mass
The mass of one atom of an isotope compared with 1/12 of the mass of a carbon‑12 atom ($^{12}C$).

### 2. Relative atomic mass ($A_r$, Ar)
The weighted average mass of one atom of the element compared with 1/12 of the mass of a $^{12}C$ atom.
Weighted average takes the natural abundance (percentage) of each isotope into account.

### Calculation formula (DSE required)
Suppose element X has two isotopes: isotope 1 (mass $m_1$, abundance $a_1\%$), isotope 2 (mass $m_2$, abundance $a_2\%$)
$$A_r=\frac{m_1\times a_1+m_2\times a_2}{100}$$

Example: Chlorine has $^{35}Cl$ (75 %) and $^{37}Cl$ (25 %)
$$A_r(Cl)=\frac{35\times75+37\times25}{100}=35.5$$

## 5.6 Electronic arrangement of atoms
![[Ch5_002.png|559]]
### Rules for filling electrons into ==electron shells== (DSE rules)
1. ==1st shell== (innermost): holds maximum 2 electrons.
2. ==2nd shell==: holds maximum 8 electrons.
3. Electrons fill inner shells first before filling outer shells.
4. ==Outer‑most shell== electrons are called valence electrons, which determine chemical properties of the element.

### Electron arrangement notation
Write numbers of electrons in each shell from inner to outer, separated by commas.
Example: Sodium (atomic number 11): electron arrangement 2,8,1.

### Periodic table link (DSE key point)
‑Number of electron shells = period number in periodic table.
‑Number of valence electrons = group number (for main group elements).
Elements with the same number of valence electrons have similar chemical properties.

## DSE Common Misconceptions
1. ❌ Isotopes have different chemical reactions
✅ Same number of valence electrons, chemical properties identical, only physical properties differ.
2. ❌ Relative atomic mass is just the average of isotope masses
✅ It is weighted average, considering percentage abundance of each isotope.
3. ❌ Electrons contribute greatly to atomic mass
✅ Electron mass is negligible, atomic mass mainly comes from nucleus (protons + neutrons).
4. ❌ Electrons fill outer shells first
✅ Inner shells must be fully filled before filling outer shells.
